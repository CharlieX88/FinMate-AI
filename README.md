## 📖 About The Project

**FinMate AI** is a Final Year Major Project designed to solve real-world personal finance problems. Most people take loans without understanding the long-term impact of interest, or fail to track their expenses, leading to financial stress. 

FinMate AI acts as a **24/7 Personal Financial Advisor**, using **Large Language Models (Llama 3 via Groq)** to analyze user data and provide actionable, personalized advice.

### ✨ Key Features

- **🤖 AI Financial Mentor:** A persistent AI chatbot that knows your income, expenses, and goals. It answers complex financial queries in English and Hinglish.
- **🏦 Loan Explorer & Simulator:** Browse curated bank loan schemes, calculate EMIs, and use the "What-If" simulator to see how prepayments can save you lakhs in interest.
- **📊 Smart Budget Tracker:** A month-wise expense tracker with dynamic pie charts and AI-generated spending insights to help you cut down unnecessary costs.
- **📈 Credit Score Simulator:** A rule-based engine that estimates your CIBIL score based on 5 financial pillars. It provides an AI Action Plan to improve your score.
- **📚 Learn Center (LMS):** Interactive learning modules (Basics, Debt, Investing) with deep-dive articles, key takeaways, and quizzes to make users financially literate.
- **🔐 Secure Authentication:** JWT-based login/signup with secure HTTP-only cookies and password hashing.
- **🌗 Dark/Light Mode:** A fully responsive UI with modern Framer Motion animations.

## 🛠️ Tech Stack

### Frontend
- **React.js (Vite):** Fast, modern frontend framework.
- **Tailwind CSS:** Utility-first styling with Dark Mode support.
- **Framer Motion:** Smooth page transitions and micro-animations.
- **Recharts:** Beautiful, responsive data visualization charts.
- **React Router DOM:** Client-side routing.

### Backend
- **Node.js & Express.js:** RESTful API architecture.
- **MongoDB & Mongoose:** NoSQL database for flexible data modeling.
- **JSON Web Tokens (JWT) & Bcrypt.js:** Secure authentication.
- **Groq SDK:** Blazing fast AI inference.
